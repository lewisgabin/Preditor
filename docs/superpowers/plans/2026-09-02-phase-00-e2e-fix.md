# Phase 0 E2E Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the complete Phase 0 Sanctum login E2E pass reproducibly on GitHub Actions without weakening coverage or production configuration.

**Architecture:** Keep the SPA and API behind the existing local Nginx same-origin proxy. Use host-only cookies in local Compose and explicit stateful/CORS allowlists for both supported loopback hostnames, while production continues to require its own domain variables. Strengthen Playwright to observe CSRF, login, cookies, authenticated `me`, health, CORS, and console state.

**Tech Stack:** Laravel 13, Sanctum, Pest, React 19.2, Playwright, Docker Compose, GitHub Actions.

---

### Task 3: Correct local domains and protect the ephemeral credential

**Files:**
- Modify: `docker-compose.yml`
- Modify: `.github/workflows/ci.yml`

- [ ] **Step 1: Make local cookies host-only**

Set local `SESSION_DOMAIN` to an overridable empty default. Set overridable exact defaults for `SANCTUM_STATEFUL_DOMAINS` and `CORS_ALLOWED_ORIGINS`, covering `localhost` and `127.0.0.1` on ports 5173/5174 plus API port 8080 where applicable.

Use these literal overridable defaults:

```text
SANCTUM_STATEFUL_DOMAINS=localhost:5173,127.0.0.1:5173,localhost:5174,127.0.0.1:5174,localhost:8080,127.0.0.1:8080
CORS_ALLOWED_ORIGINS=http://localhost:5173,http://127.0.0.1:5173,http://localhost:5174,http://127.0.0.1:5174
```

- [ ] **Step 2: Align CI host and port explicitly**

Set `WEB_PORT=5173` and `E2E_BASE_URL=http://127.0.0.1:5173` in the E2E job. Run `scripts/wait-for-health.sh` separately for the SPA and API before Playwright. Keep its condition-based polling and bounded attempt count; do not add a fixed sleep.

- [ ] **Step 3: Mask the generated password**

Emit `::add-mask::` before writing the generated value to `GITHUB_ENV`, and continue sending it to Artisan only through stdin.

- [ ] **Step 4: Verify production remains explicit**

Confirm `docker-compose.prod.yml` still requires `SESSION_DOMAIN`, `SANCTUM_STATEFUL_DOMAINS`, and `CORS_ALLOWED_ORIGINS`; do not add local fallbacks there.

- [ ] **Step 5: Preserve strict failure behavior**

Confirm no step uses `continue-on-error`, no Playwright assertion is removed, no `test.skip` remains, and health/navigation waits use conditions with bounded timeouts rather than fixed sleeps.
