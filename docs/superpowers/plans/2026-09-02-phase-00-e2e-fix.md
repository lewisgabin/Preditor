# Phase 0 E2E Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the complete Phase 0 Sanctum login E2E pass reproducibly on GitHub Actions without weakening coverage or production configuration.

**Architecture:** Keep the SPA and API behind the existing local Nginx same-origin proxy. Use host-only cookies in local Compose and explicit stateful/CORS allowlists for both supported loopback hostnames, while production continues to require its own domain variables. Strengthen Playwright to observe CSRF, login, cookies, authenticated `me`, health, CORS, and console state.

**Tech Stack:** Laravel 13, Sanctum, Pest, React 19.2, Playwright, Docker Compose, GitHub Actions.
